# Chromux Next v0.1.1 branding UAT

Automated verification:

```sh
cd chromux-next
npm run icons
npm run verify
```

Manual qualification:

1. Place legacy Chromux and Chromux Next side by side in Finder or the Dock.
2. Confirm legacy Chromux retains its right-facing three-node chevron.
3. Confirm Chromux Next uses the upward-facing three-node chevron with the same
   orange, purple, and green family colors.
4. Start Chromux Next and confirm the upward-chevron mark appears beside the
   product name in the left workspace rail.
5. Confirm the app name and bundle identity remain GBlockParty Chromux Next and
   `dev.georgele.chromux.next`.
