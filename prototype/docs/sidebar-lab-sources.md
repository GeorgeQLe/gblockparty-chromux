# Sidebar Lab research/source index

These sources informed hypotheses, not visual branding. Every concept uses the
Chromux lab palette and identical fixture identities.

- **Chromux Current Hybrid:** production Threads priority partitions and
  grouped remainder.
- **Cursor:** [Cursor 1.4 changelog](https://cursor.com/changelog/1-4) —
  unified foreground/background agent visibility and search.
- **Linear:** [Triage](https://linear.app/docs/triage) and
  [Favorites](https://linear.app/docs/favorites) — dedicated triage beside
  stable personal navigation.
- **T3 Code:** [SidebarV2 source](https://github.com/pingdotgg/t3code/blob/9dd425b2234c062b4767583e42d4b2c1aabab15d/apps/web/src/components/SidebarV2.tsx)
  — active cards with lower-density snoozed and settled shelves.
- **Codex:** [Introducing the Codex app](https://openai.com/index/introducing-the-codex-app/)
  — project-organized parallel threads and worktree identity.
- **Claude Code Desktop:** [Manage sessions](https://code.claude.com/docs/en/desktop#manage-sessions)
  — project/status/environment filters and paired session viewing.
- **Zed:** [Parallel agents](https://zed.dev/docs/ai/parallel-agents) —
  project threads and searchable history.
- **agmux:** [agmux](https://agmux.dev/) — stable navigation plus Mission
  Control.
- **Vibe Kanban:** [Vibe Kanban](https://www.vibekanban.com/) — task lifecycle
  and review state.
- **Focus Split:** Chromux synthesis hypothesis: persistent project/session
  navigation plus a contextual two-session strip.
